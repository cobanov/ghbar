What it does

Only what's waiting on you

Pull requests and issues other people opened on your repositories, reviews requested from you, and your own open pull requests. Add organizations or other accounts in Settings.

Green until you've seen it

The number in the menu bar counts what's new. Open an item, or mark a whole tab as seen, and it turns grey.

Works from the keyboard

Move through the list, open a row, switch tabs and refresh without the mouse.

↑↓ move Return open ←→ tabs ⌘R refresh ⌘, settings
Your token stays on your Mac

Sign in with GitHub, or continue as the account the GitHub CLI uses. The token is kept in the Keychain, and GHBar talks only to GitHub: no server, no analytics.

Light on the rate limit

One GraphQL request per refresh, every five minutes by default, and again when the Mac wakes or comes back online.

Install

Terminal
curl -fsSL https://ghbar.cobanov.dev/install.sh | sh

Downloads the latest release, checks that Apple notarized it, puts GHBar in Applications and opens it. Run it again to update. Read the script.

Homebrew
brew install --cask cobanov/tap/ghbar

Update with brew upgrade --cask ghbar.

Download

GHBar-macos.zip from the latest release. Unzip it and move GHBar to Applications.

Requirements

macOS 14 Sonoma or later, and a GitHub account.
