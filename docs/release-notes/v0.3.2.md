The rest of the review.

- **The panel works from the keyboard.** ↑ and ↓ move between rows, Return
  opens one (or a repository group), ← and → switch tabs, Escape closes.
  Menus opened without a click appear under the window, never on another
  display.
- A tab's green number now counts what is new in it; grey is the total when
  nothing is.
- When GitHub refuses a token, GHBar says so, instead of claiming the GitHub
  CLI is signed out.
- After the Mac wakes, or after a refresh failed offline, GHBar refreshes as
  soon as the network is back rather than after a fixed pause.
- Settings › Repositories no longer shows "0" next to repositories that had
  nothing open at the last refresh.
