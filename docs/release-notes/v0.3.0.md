A new panel in place of the menu.

### New

- **The panel.** Clicking GHBar now opens a dark panel that hangs from the
  menu bar instead of a system menu.
  - Pull requests, issues, reviews and your own PRs are tabs with counts.
    Each tab scrolls, so nothing is cut off at "N more…".
  - Every row shows who opened it, with their GitHub picture.
  - Green marks what you haven't seen yet.
  - Repository groups open in place.
- The shortcuts still work: ⌘R refresh, ⌘, settings, ⌘O GitHub, ⌘Q quit.

### Removed

- **Settings → Menu height.** The panel scrolls instead.

### Install / upgrade

```bash
brew upgrade --cask ghbar        # or: brew install --cask cobanov/tap/ghbar
```
