Sign-in that says what it is doing, and fixes from a full review.

### Sign-in

- GHBar now has one sign-in state: signed out, signed in (with GitHub or
  through the GitHub CLI), or expired. Settings › GitHub account shows which,
  with Sign Out and a way to change repository access.
- Sign Out stays signed out; it no longer falls back to `gh` on its own.
- A new install asks before using the GitHub CLI's account: "Continue as
  @you" in the welcome window. Installs that already used `gh` keep doing so.
- Only the github.com token is taken from `gh`, never an Enterprise one.
- The welcome window opens by itself while nobody is signed in, can be
  cancelled, and keeps waiting through a dropped connection.

### Fixes

- Seen and notified marks survive filters: hiding a repository, an
  organization or bots for a while no longer brings everything back as new.
- A pull request that moves to a stronger signal (changes requested, review
  requested) is new again and notified.
- Your own pull requests no longer send notifications or count in the badge.
- Hiding a tab no longer hides its items from the other tabs too.
- Rate limits use GitHub's reset time, and refreshes pause until then; a 403
  that is not a rate limit says so.
- Data GitHub returns alongside a partial error is shown, with the error as a
  note.
- Results arrive newest first when a search has more than 100.
- A refresh still running at Sign Out can no longer bring the old account back.
- The panel no longer gets clipped by long counts or five tabs, closes when you
  switch apps, and reads better with VoiceOver.
