Bug fix release.

### Fixed

- **Repeated notifications for old items.** GHBar was re-notifying about the
  same pull requests and issues on every refresh — every five minutes — even
  when nothing new had arrived. The app tracked "seen" (the grey/green state
  in the menu, cleared when you click a row) and used the same record to decide
  what to notify about; since items stay unseen until you click them, every
  refresh looked like a pile of news. Notifications now keep their own record:
  each item is notified at most once, independently of whether you've clicked
  it. Existing installs migrate silently — no notification burst after
  updating.

### Install / upgrade

```bash
brew upgrade --cask ghbar        # or: brew install --cask cobanov/tap/ghbar
```
