The new GHBar: a panel in place of the menu, and sign-in without the GitHub CLI.
Everything below is new if you are coming from 0.1.

- **A panel instead of a menu.** Reviews waiting on you, pull requests and issues
  people opened on your repositories, and your own pull requests, as tabs with
  counts. Every row shows who opened it; green marks what you haven't seen.
- **Sign in with GitHub** from the welcome window. If the GitHub CLI is signed
  in, continue as that account in one click.
- **Settings** for other users and organizations, hidden repositories, refresh
  interval, notifications and launch at login.
- **Keyboard:** ↑ ↓ and Return in the list, ← → between tabs, ⌘R to refresh.
- Refreshes when the Mac wakes or comes back online.
- Fixed in 0.3.3: the refresh button stops turning when a refresh ends.

### Install

```sh
curl -fsSL https://ghbar.cobanov.dev/install.sh | sh
```

or `brew install --cask cobanov/tap/ghbar` (`brew upgrade --cask ghbar` to update).
